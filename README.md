# Geldium Credit Delinquency Analysis — Tata iQ / Forage

Credit risk analytics project completed as part of the **Tata iQ / Geldium Finance AI Transformation Consultant** simulation on Forage (certified).

**Author:** Aisha O. Inuwa

---

## What I did

Analyzed a 500-customer credit card dataset to identify delinquency risk drivers and propose a collections strategy.

1. **Data cleaning** — handled missing values (Income, Credit Score, Loan Balance), standardized Employment_Status labels, capped out-of-range Credit_Utilization values.
2. **Exploratory analysis** — profiled delinquency rates by card type, employment status, and location; examined payment history patterns.
3. **Predictive model plan** — proposed a logistic regression approach with feature rationale, threshold strategy, and fairness considerations.
4. **Collections strategy** — designed a risk-tiered outreach system with an agentic AI component and 90-day pilot plan.
